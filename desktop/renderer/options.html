🔊 Read Aloud Pro – Settings

A profile is a saved set of word groups, each with its own colour. Switch profiles from the panel's Find tab. In a term list, separate terms with commas. A * at the end matches any ending (injur* = injury, injured). Plurals match automatically.

Voice

Windows voices (David, Mark, Zira) give exact word highlighting. For free natural-sounding voices, install this extension in Microsoft Edge too: Edge adds "Online (Natural)" voices such as Aria, Guy and Jenny. These always play through the Windows default speaker.

Every sentence read uses characters (about 1 per letter, or half that on Flash). A 500-word email is about 3,000 characters. Use your own voices or ElevenLabs library voices. Do not clone anyone's voice without their consent.

Speaker

Choosing a speaker works with ElevenLabs voices (they play as audio files). Built-in voices always use the Windows default; to move them, use Windows Settings → System → Sound → Volume mixer → Chrome → Output device. Listing speakers asks for microphone permission once (Chrome only shows speaker names after that).
